# Login-Credentials - JE5

A simple Java Web Application for User Login using Servlet and JSP.

## Technologies Used
- Java
- Servlet / JSP
- Eclipse IDE
- Apache Tomcat Server
- HTML / CSS

## Project Structure
- src/main/java/com/tap/controller/Servlet.java - Main Controller
- src/main/webapp - JSP and HTML Pages

## How to Run
1. Clone this repository
2. Import into Eclipse as Dynamic Web Project
3. Run on Apache Tomcat Server
4. Open in browser:http://localhost:8080/JE5/login.html
